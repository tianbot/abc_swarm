# ABC Swarm

Ant Bee Cooperative Swarm, indicating air-ground cooperation. This repository is for Tianbot Mini and RoboMaster TT swarm kit.

## Usage

View the [usage](usage.md) for more details.

## Documentation

how to build the documentation and view it:

```bash
pip3 install sphinx-rtd-theme
cd docs && make html
xdg-open "build/html/index.html"
```
